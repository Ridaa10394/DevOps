## What is IaC (quick recap)

Infrastructure as Code means describing servers, networks, buckets etc. in files instead of clicking around the console. Those files go in git, get reviewed in PRs, and can be applied again and again to get the exact same result.

Terraform specifically:

- **Declarative** - I write what I want to exist, Terraform works out the create/update/delete steps.
- **Providers** - plugins that talk to the APIs (AWS, Azure, GCP, Kubernetes, GitHub, random...).
- **State** - `terraform.tfstate` maps the code to the real resources. It can contain sensitive values, so it never goes in git (that's what `.gitignore` here is for). In a team it lives in a remote backend like S3.
- **Plan before apply** - you always see the diff before anything changes.
